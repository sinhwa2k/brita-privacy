브리타 매니저 개인정보처리방침

시행일: 2026-11-24

브리타 매니저(패키지 com.sinhwa2k.brita, 이하 "앱")는 개인이 개발한 브리타 정수 필터 사용량 관리 앱입니다. 이 방침은 앱이 어떤 정보를 어떻게 다루는지 설명합니다.

1. 수집하는 정보

개발자가 수집하는 정보: 없음. 앱은 자체 서버가 없고 회원가입, 로그인, 결제, 위치·연락처·사진 등의 권한을 사용하지 않습니다.

기기 안에만 저장되는 정보 (개발자나 제3자에게 전송되지 않음)

  • 필터 용량, 1회 정수량 등 사용자가 입력한 설정값
  • 필터 사용량과 초기화 일자

이 정보는 앱 삭제 또는 기기의 "설정 > 앱 > 브리타 매니저 > 저장공간 > 데이터 삭제"로 모두 삭제됩니다.

광고 SDK 가 수집하는 정보 (Google AdMob)

앱은 광고 표시를 위해 Google Mobile Ads SDK 를 사용하며, 이 SDK 는 다음 정보를 자동으로 수집·공유할 수 있습니다.

  • IP 주소(대략적인 위치 추정에 사용될 수 있음)
  • 앱 사용 상호작용(앱 실행, 탭 등)
  • 진단 정보(앱·SDK 성능, 실행 시간, 응답 없음 비율, 에너지 사용 등)
  • 기기·계정 식별자(Android 광고 ID, 앱 세트 ID 등)

자세한 내용은 Google 안내와 Google 개인정보처리방침, Google 광고 정책의 데이터 사용을 참고하세요.

2. 이용 목적

  • 광고 제공 및 광고 성과 측정
  • 부정 클릭 방지 등 사기 방지와 서비스 보안
  • 앱·SDK 성능 분석

개발자는 이 정보에 접근하지 않으며, 자체 분석·크래시 수집 도구도 사용하지 않습니다.

3. 제3자 제공

광고 정보는 광고 제공자인 Google LLC(AdMob) 에게 전송됩니다. 다른 제3자에게 제공하지 않습니다. 전송은 TLS 로 암호화됩니다.

4. 보관 및 삭제

  • 앱 내 정보: 기기에만 있으며 앱 삭제 시 함께 삭제됩니다.
  • 광고 정보: Google 의 정책에 따라 보관됩니다. 개발자는 이를 삭제할 수 없으나 아래 5항으로 사용을 제한·삭제할 수 있습니다.
  • 삭제나 열람 요청은 아래 문의처로 보내세요.

5. 광고 개인 맞춤 설정 거부 방법

  • Android 설정 > Google > 광고(또는 개인정보 보호 > 광고)에서 "광고 ID 삭제" 또는 "광고 개인 최적화 사용 안 함"
  • Google 광고 설정: https://adssettings.google.com

6. 아동 정책

앱은 만 13세 미만 아동을 대상으로 하지 않으며 아동의 개인정보를 알면서 수집하지 않습니다. 아동의 정보가 수집된 사실을 알게 되면 즉시 삭제합니다.

7. 방침 변경

방침이 바뀌면 이 문서를 갱신하고 시행일을 고칩니다.
